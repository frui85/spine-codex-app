# SpineCodex App v26.901.51231.1 中文发布说明

[English release notes](RELEASE_NOTES_v26.901.51231.1.md)

本次是适配 **Codex Desktop 26.901.51231** 的 App UI 修订，解决树层级过深导致文字挤成竖排，以及长历史默认展开过多的问题。

## 展示优化

- 视觉缩进最多42px，同时不超过可用宽度18%；父子关系与节点ID不变，深层行附展示层级。
- 标题最多两行，悬停查看规范化后的完整标题，点击任务仍进入原详情。层级与数量信息移至标题下方，避免挤压正文。
- 默认保留当前上下文投影末尾20条展示记录，早期记录可点击展开、再次收起；运行中节点、Spawn进度与选中项保留可见，因此总数可能超过20。
- 该折叠不删除历史、不触发模型上下文压缩，也不代表20轮对话。原有“早期上下文”“第N次压缩前”“之前的分支”继续按原含义工作。
- 移除只投影前300行的截断，避免深层树的活跃末端被遗漏；主动展开后可能渲染更多历史记录。
- 原有节点/Spawn图标SVG、状态映射及点击操作含义均保留。

## 验证与效果

使用生产Renderer投影、行渲染、图标及折叠处理函数，配合80层模拟数据测试：展开显示80条记录和1个控制入口，收起恢复20条记录和1个入口。另覆盖350层、活跃节点保留、会话隔离以及180–480px请求面板宽度下无横向溢出。
